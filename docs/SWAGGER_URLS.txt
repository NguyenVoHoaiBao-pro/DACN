=== Auth / JWT ===
1. POST http://localhost:8081/api/auth/login  (hoặc qua gateway :8080)
2. Body: { "username": "...", "password": "..." }
3. Authorize: Bearer <accessToken>
4. Refresh token (UUID) — KHONG dung lam Bearer cho API khac

Can Redis trong .env (REDIS_URL) cho login/refresh.
Xem: docs/ENV_AND_REDIS.md, docs/AUTH_SERVICE.md
